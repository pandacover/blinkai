# Blinkai

Solo webapp that turns a user's idea into an assembled short film via OpenRouter.

## Language

**Film**:
The assembled short audiovisual piece the user can watch at the end of a run.
_Avoid_: movie, video (when meaning the finished piece), render

**Film Plan**:
The structured textual blueprint (story, shots, and media prompts) produced before media is generated.
_Avoid_: script (alone), screenplay (alone), storyboard (alone)

**Brief**:
The user's starting input that kicks off a run.
_Avoid_: prompt (as the product noun), query, request

**Still**:
A single generated image used as a visual beat in the Film.
_Avoid_: image, frame (when meaning a generated asset)

**Clip**:
A short generated moving-image segment used as a visual beat in the Film.
_Avoid_: video snippet, scene video

**Assembly**:
The step that combines Stills, Clips, and any audio into one Film.
_Avoid_: export, render, compose (when meaning this product step)

**Run**:
One end-to-end attempt from Brief through Film Plan and media to Assembly.
_Avoid_: job, session, generation (when meaning the whole pipeline)

**Project**:
A locally saved Run (Brief, Film Plan, assets, and assembled Film state) that survives reloads.
_Avoid_: document, workspace, file set

**Voiceover**:
Spoken narration generated by TTS and laid under the visual beats during Assembly.
_Avoid_: TTS track (as the product noun), dialogue track (unless meaning character speech specifically)

**Timeline Player**:
The in-browser player that plays the Assembled sequence of Stills/Clips with Voiceover; V1's Film delivery surface (not an MP4 download).
_Avoid_: video player, exporter
